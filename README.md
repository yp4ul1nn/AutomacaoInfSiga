## 📌 Sobre o projeto

Projeto de automação desenvolvido em **Python** para coleta, processamento e organização de dados do Infosiga SP, com foco no município de Diadema.

A solução integra automação de dados e visualização no Power BI, facilitando a análise de indicadores de segurança viária.

## ⚙️ Pipeline de dados

```text
📥 Dados Infosiga SP
        ↓
🐍 Processamento Python
        ↓
🧹 Tratamento e filtragem
        ↓
📊 Power BI
        ↓
📈 Análise de indicadores
```

## 🚀 Funcionalidades

- Automatização do processamento de dados;
- Filtragem de registros de Diadema;
- Organização de dados por período;
- Tratamento de informações para análise;
- Preparação de dados para dashboards;
- Integração com ferramentas de Business Intelligence.

## ▶️ Como executar

**1. Instale as dependências**

```bash
pip install -r requirements.txt
```

**2. Execute a automação**

```bash
python main.py
```

Ou utilize o arquivo:

```text
executar_infosiga.bat
```
